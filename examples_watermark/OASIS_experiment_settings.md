# OASIS实验设置

## 1. Agent配置

| 参数 | Twitter | Reddit |
|------|---------|--------|
| 水印组 (A组) | 5个Agent | 5个Agent |
| 对照组 (B组) | 5个Agent | 5个Agent |
| Agent总数 | 10 | 10 |
| 模拟步数 | 10 | 10 |

## 2. API与LLM配置

| 参数 | 值 |
|------|-----|
| API提供商 | DeepSeek |
| 模型 | deepseek-chat |
| API地址 | https://api.deepseek.com |
| Token限制 | 16000 |
| 上下文窗口 | 10 |

## 3. 可选行为

### Twitter平台

```
create_post, like_post, repost, follow, do_nothing, quote_post
```

### Reddit平台

```
create_post, create_comment, like_post, dislike_post, like_comment, dislike_comment, search_posts, search_user, trend, refresh, do_nothing, follow, mute
```

## 4. 水印配置

| 参数 | 值 |
|------|-----|
| 水印方案 | 差分方案 (Differential Scheme) |
| 纠错方法 | parity (奇偶校验) |
| 嵌入策略 | cyclic (循环嵌入) |
| 上下文窗口 | 3 (最近3个行为作为PRG种子) |
