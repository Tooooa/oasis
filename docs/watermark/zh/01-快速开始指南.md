# 快速开始指南（验证水印）

本指南只保留“验证水印是否工作”的最短路径：直接运行 `examples_watermark/01_basic/custom_agent_run_with_profile.py`。

## 前置要求

- Python 3.8+
- 可用的 LLM API（DeepSeek 或 OpenAI）
- 4GB+ 内存（小规模实验）

## 1) 安装

在项目根目录（`oasis/`）：

```bash
pip install -e .
```

## 2) 配置 API

二选一即可：

- **方式 A：用 `config.json`**：复制 `config.json.template` 为 `config.json`，填入 `deepseek.api_key` 或 `openai.api_key`。
- **方式 B：用环境变量**：设置 `DEEPSEEK_API_KEY` 或 `OPENAI_API_KEY`（脚本也会读取）。

> 如需调整 Agent 数、轮数、profile 路径：在 `config.json`/`config_watermark.json` 里修改（脚本会按优先级自动查找配置文件）。

## 3) 运行真实 OASIS + 水印验证

在项目根目录（`oasis/`）：

```bash
python examples_watermark/01_basic/custom_agent_run_with_profile.py
```

成功的标志：脚本结尾会打印每个 Agent 的水印提取结果，并出现 `Agent ID 匹配` / `验证成功` 之类的提示。

## 4) 产物位置

- 数据库：`outputs/databases/current/*.db`
- 水印日志：`outputs/logs/watermark/<YYYY-MM>/*.log`（或配置里的 `log_dir`）
