## 🚀 三步上手

### 步骤 1: 配置 API

```bash
# 进入项目目录
cd oasis

# 复制配置模板
cp config.json.template config.json
```

编辑 `config.json`：

```json
{
    "api_provider": "deepseek",  // 或 "openai"
    "deepseek": {
        "api_key": "你的-API-KEY",
        "base_url": "https://api.deepseek.com",
        "model": "deepseek-chat"
    },
    "num_agents": 2,
    "num_rounds": 3
}
```

### 步骤 2: 运行示例

```bash
# 运行基础示例（最简单）
python examples_watermark/01_basic/custom_agent_run.py
```

程序会输出类似：

## 📊 结果解读

### 1. 嵌入阶段

```
Agent 0: 3/9 bits (剩余: 6)
```

- `3/9` = 已嵌入 3 bits，总共 9 bits（8-bit agent_id + 1-bit parity）
- `剩余: 6` = 还需要 6 bits 才能完成完整的水印块

### 2. 提取阶段

```
识别的agent_id: 0 (binary: 00000000)
✅ Agent ID 匹配！
```

- 成功从日志中提取水印
- 解码出 agent_id = 0
- 与预期的 Agent 0 匹配

### 3. 验证状态

```
📈 比特位准确度:
   - 匹配度: 100.0%
   ✅ 完美匹配
```

- `100%` = 所有提取的 bits 都正确
- 水印系统工作正常

## ❓ 常见问题

### Q1: ModuleNotFoundError: No module named 'oasis'

**解决**:
```bash
# 确保在项目根目录
cd oasis

# 重新安装
pip install -e .
```

### Q2: API Key 错误

**解决**:
```bash
# 检查配置文件
cat config.json

# 确保 API Key 正确
# DeepSeek: 以 sk- 开头
# OpenAI: 以 sk- 开头
```

### Q3: 水印准确度低于 100%

**原因**:
- 模拟轮数太少，未嵌入完整水印块
- 概率分布太集中，部分轮跳过嵌入

**解决**:
```json
{
    "num_rounds": 10  // 增加轮数到 10+
}
```
