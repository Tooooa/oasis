### 2. WatermarkSampler

**位置**: `oasis/watermark/watermark_sampler.py`

**职责**:
- 实现差分水印采样算法
- 通过排序重组嵌入 bit

**核心算法**:

```python
def differential_based_recombination(
    sorted_behaviors: List[Tuple[str, float]],
    bit: str,
    delta: float = 2.0,
    gamma: float = 0.25
) -> Tuple[str, List[float]]:
    """
    差分采样算法
    
    参数:
        sorted_behaviors: 按概率排序的行为列表 [(behavior, prob), ...]
        bit: 要嵌入的 bit ("0" 或 "1")
        delta: 偏移强度
        gamma: 平滑系数
    
    返回:
        selected_behavior: 选中的行为
        updated_probs: 更新后的概率分布
    """
    # Step 1: 根据 bit 重组行为
    if bit == "1":
        # bit=1: 保持原顺序
        reordered = sorted_behaviors
    else:
        # bit=0: 交换前两个
        reordered = [sorted_behaviors[1], sorted_behaviors[0]] + sorted_behaviors[2:]
    
    # Step 2: 计算带偏移的 logits
    logits = []
    for i, (behavior, prob) in enumerate(reordered):
        if i == 0:
            # 第一个行为添加偏移
            logit = np.log(prob + 1e-10) + delta
        else:
            logit = np.log(prob + 1e-10)
        logits.append(logit)
    
    # Step 3: Softmax + gamma 平滑
    probs = softmax(logits, gamma)
    
    # Step 4: 采样
    selected_idx = np.random.choice(len(reordered), p=probs)
    selected_behavior = reordered[selected_idx][0]
    
    return selected_behavior, probs
```

**算法图解**:

```
原始概率分布:
┌──────────────┬──────────────┬──────────────┐
│ create_post  │  like_post   │  comment     │
│    0.45      │    0.35      │    0.20      │
└──────────────┴──────────────┴──────────────┘

嵌入 bit = "1" (保持顺序):
┌──────────────┬──────────────┬──────────────┐
│ create_post  │  like_post   │  comment     │
│  0.45 + δ    │    0.35      │    0.20      │
│   ↓ Softmax  │              │              │
│    0.52      │    0.30      │    0.18      │
└──────────────┴──────────────┴──────────────┘

嵌入 bit = "0" (交换前两个):
┌──────────────┬──────────────┬──────────────┐
│  like_post   │ create_post  │  comment     │
│  0.35 + δ    │    0.45      │    0.20      │
│   ↓ Softmax  │              │              │
│    0.41      │    0.40      │    0.19      │
```

### 3. ECC 模块

**Parity ECC**:

```python
def parity_encode(payload: str) -> str:
    """
    Parity 编码
    
    计算偶校验位:
    - 1 的数量为偶数 → parity = 0
    - 1 的数量为奇数 → parity = 1
    
    示例:
        payload = "11001101" (5个1，奇数)
        parity = 1
        encoded = "110011011"
    """
    ones_count = payload.count('1')
    parity = '1' if ones_count % 2 == 1 else '0'
    return payload + parity

def parity_decode(encoded: str) -> Tuple[str, bool]:
    """
    Parity 解码
    
    验证校验位:
    - 计算 payload 中 1 的数量
    - 检查与 parity bit 是否匹配
    
    返回:
        payload: 解码后的 payload
        valid: 校验是否通过
    """
    payload = encoded[:-1]
    parity_bit = encoded[-1]
    
    ones_count = payload.count('1')
    expected_parity = '1' if ones_count % 2 == 1 else '0'
    
    valid = (parity_bit == expected_parity)
    
    return payload, valid
```

**ECC 工厂模式**:

```python
class ECCFactory:
    """ECC 方法工厂"""
    
    _methods = {
        "parity": ParityECC,
        # 可扩展: "hamming": HammingECC,
    }
    
    @classmethod
    def create(cls, ecc_type: str):
        """创建 ECC 编码器/解码器"""
        if ecc_type not in cls._methods:
            raise ValueError(f"Unknown ECC type: {ecc_type}")
        return cls._methods[ecc_type]()
    
    @classmethod
    def register(cls, name: str, ecc_class):
        """注册新的 ECC 方法"""
        cls._methods[name] = ecc_class
```

### 4. AgentSimulator

**位置**: `oasis/watermark/agent_simulator.py`

**职责**:
- 调用 LLM 生成行为概率
- 解析 LLM 输出

**关键流程**:

```python
class AgentSimulator:
    def __init__(self, model):
        self.model = model
    
    def generate_behavior_probabilities(
        self,
        context: str,
        available_actions: List[str]
    ) -> Dict[str, float]:
        """
        生成行为概率分布
        
        流程:
        1. 构造 prompt
        2. 调用 LLM
        3. 解析输出
        4. 归一化概率
        """
        # Step 1: 构造 prompt
        prompt = self._build_prompt(context, available_actions)
        
        # Step 2: 调用 LLM
        response = self.model.generate(prompt)
        
        # Step 3: 解析输出
        probabilities = self._parse_response(response)
        
        # Step 4: 归一化
        total = sum(probabilities.values())
        probabilities = {k: v/total for k, v in probabilities.items()}
        
        return probabilities
    
    def _build_prompt(self, context: str, actions: List[str]) -> str:
        """构造 prompt"""
        return f"""
You are a social media user. Based on the following context, 
estimate the probability of each action.

Context: {context}

Available actions:
{chr(10).join(f"- {action}" for action in actions)}

Please output in JSON format:
{{
    "action1": probability1,
    "action2": probability2,
    ...
}}
"""
    
    def _parse_response(self, response: str) -> Dict[str, float]:
        """解析 LLM 输出"""
        import json
        import re
        
        # 提取 JSON
        json_match = re.search(r'\{.*\}', response, re.DOTALL)
        if json_match:
            return json.loads(json_match.group())
        
        # 解析失败，返回均匀分布
        return {}
```

```python
# OASIS 核心: SocialAgent (不修改)
class SocialAgent:
    def __init__(
        self,
        agent_id: int,
        # ... 其他参数 ...
        watermark_manager: Optional[WatermarkManager] = None  # 新增可选参数
    ):
        self.agent_id = agent_id
        self.watermark_manager = watermark_manager  # 保存引用
        # ... 其他初始化 ...
    
    def perform_action_by_llm(self, context: str):
        """生成行为（可能包含水印）"""
        # 1. 生成行为概率
        probabilities = self._generate_probabilities(context)
        
        # 2. 如果启用水印，通过 WatermarkManager 采样
        if self.watermark_manager and self.watermark_manager.enabled:
            behavior, targets, _, _ = self.watermark_manager.sample_behavior_watermark(
                probabilities=probabilities,
                round_num=self.current_round,
                context_for_key=context
            )
        else:
            # 否则，正常采样
            behavior = self._sample_behavior(probabilities)
        
        # 3. 执行行为
        self._execute_behavior(behavior)
```

**优势**:
- ✅ 核心代码不变
- ✅ 向后兼容
- ✅ 易于维护
- ✅ 可以随时启用/禁用

## 数据流

### 嵌入流程

```
1. Agent 请求行为
   │
   ▼
2. LLM 生成概率分布
   │  probabilities = {"create_post": 0.45, "like": 0.35, "comment": 0.20}
   ▼
3. WatermarkManager.sample_behavior_watermark()
   │
   ├─▶ 获取下一个 bit (e.g., "1")
   │
   ├─▶ 检查概率分布是否适合嵌入
   │   │
   │   ├─▶ 适合: 继续
   │   └─▶ 不适合: 跳过嵌入，返回原概率最高的行为
   │
   ├─▶ differential_based_recombination(probabilities, bit, delta, gamma)
   │   │
   │   ├─▶ 排序行为
   │   ├─▶ 根据 bit 重组
   │   ├─▶ 添加 logit 偏移
   │   ├─▶ Softmax + gamma 平滑
   │   └─▶ 采样行为
   │
   ├─▶ 记录日志
   │   │  {"round": 0, "behavior": "create_post", "bit": "1", "embedded": true}
   │   └─▶ 写入 watermark-agentX-*.log
   │
   └─▶ 返回选中的行为
       │
       ▼
4. Agent 执行行为
```

### 验证流程

```
1. 读取日志文件
   │  watermark-agent0-20251111-143052.log
   ▼
2. 提取嵌入的 bits
   │
   ├─▶ 解析每一行 JSON
   ├─▶ 筛选 embedded=true 的记录
```

## 关键算法

### 1. 差分采样算法

**论文**: AgentMark: A Differential Watermarking Framework for Multi-Agent Systems

**核心思想**:
- 通过**排序重组**嵌入 bit
- bit=1: 保持原顺序
- bit=0: 交换前两个行为

**伪代码**:

```
Function DifferentialSampling(probabilities, bit, delta, gamma):
    // Step 1: 排序
    sorted_behaviors = sort(probabilities, descending=True)
    
    // Step 2: 重组
    if bit == "1":
        reordered = sorted_behaviors
    else:
        reordered = swap(sorted_behaviors[0], sorted_behaviors[1])
    
    // Step 3: 添加偏移
    logits = []
    for i, (behavior, prob) in enumerate(reordered):
        if i == 0:
            logit = log(prob) + delta  // 添加偏移
        else:
            logit = log(prob)
        logits.append(logit)
    
    // Step 4: Softmax + gamma 平滑
    new_probs = softmax(logits, gamma)
    
    // Step 5: 采样
    selected = sample(reordered, probabilities=new_probs)
    
    return selected
```

**参数说明**:
- **delta**: 偏移强度，越大嵌入越强
- **gamma**: 平滑系数，越大分布越平滑

### 2. Parity ECC

**原理**: 偶校验

**编码**:
```
Payload:  1 1 0 0 1 1 0 1
          │ │ │ │ │ │ │ │
1的数量: 5 (奇数)
Parity:   1 (奇校验)
Encoded:  1 1 0 0 1 1 0 1 1
```

**解码**:
```
Encoded:  1 1 0 0 1 1 0 1 1
          │ │ │ │ │ │ │ │ │
Payload:  1 1 0 0 1 1 0 1   Parity: 1
1的数量: 5 (奇数)
Expected: 1 (奇校验)
Match: ✅
```

**检测能力**: 可检测 1 bit 错误
