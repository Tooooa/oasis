# 环境配置（交接用）

本项目（`camel-oasis`）要求 Python 版本为 **3.10–3.11**（`>=3.10,<3.12`），在 Windows 上推荐使用 conda 创建独立环境。

## 1) 创建/激活 conda 环境（Python 3.11）

```bash
conda create -n oasis python=3.11 -y
conda activate oasis
```

> 如果你本机已经有 `oasis` 环境，确认版本：`python --version`。

## 2) 安装项目（editable）

在仓库根目录（`oasis/`）：

```bash
python -m pip install -U pip setuptools wheel
python -m pip install -e .
```

## 3) 配置 DeepSeek（不要提交 Key）

推荐用环境变量（更安全）：

```bash
# PowerShell
$env:DEEPSEEK_API_KEY="sk-xxx"
```

也可以在本地 `config.json` 填写（该文件已加入 `.gitignore`，不应提交）。

## 4) 快速自测（不需要 API）

```bash
python examples_watermark/02_testing/test_watermark_only.py
```

## 5) 真实 OASIS + DeepSeek 跑水印（需要 API）

```bash
python examples_watermark/01_basic/custom_agent_run_with_profile.py
```

### 常见注意事项（Windows）

- `conda run` 在某些 GBK 控制台下可能会因为输出编码报错；建议直接在激活的环境里运行 `python ...`。
- 若水印日志验证提示 “不足一个完整块（parity: 9 bits）”，把 `config.json` 里的 `num_rounds` 调大（例如 12+）再跑一次。
