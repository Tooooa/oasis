## 基础配置

### 配置文件说明

OASIS 支持多种配置方式，优先级从高到低：

1. **代码中直接指定** - 最高优先级
2. **配置文件** (`config.json`) - 中等优先级  
3. **环境变量** - 最低优先级

#### 配置文件位置

系统会按以下顺序查找配置文件：

```python
# 自动查找顺序
1. ./config.json                    # 当前目录
2. ./examples_watermark/config.json # 示例目录
3. ./oasis/config.json              # 项目根目录
```

#### 创建配置文件

使用模板创建配置文件：

```bash
# 复制模板
cp config.json.template config.json

# 编辑配置
notepad config.json  # Windows
vim config.json      # Linux/Mac
```

#### 配置文件结构

```json
{
  "model": {
    "platform": "openai",
    "type": "deepseek-chat",
    "url": "https://api.deepseek.com",
    "api_key": "sk-xxx"
  },
  "watermark": {
    "enabled": true,
    "bit_stream": "11001101",
    "delta": 2.0,
    "gamma": 0.25,
    "ecc_type": "parity",
    "log_dir": "outputs/logs/watermark"
  },
  "database": {
    "path": "outputs/databases/current/oasis.db"
  }
}
```

### 环境变量配置

如果不想创建配置文件，可使用环境变量：

**Windows PowerShell**:

```powershell
# 设置 API Key
$env:OPENAI_API_KEY = "sk-xxx"
$env:DEEPSEEK_API_KEY = "sk-xxx"

# 设置水印参数
$env:WATERMARK_ENABLED = "true"
$env:WATERMARK_BIT_STREAM = "11001101"
```

**Linux/Mac**:

```bash
# 设置 API Key
export OPENAI_API_KEY="sk-xxx"
export DEEPSEEK_API_KEY="sk-xxx"

# 设置水印参数
export WATERMARK_ENABLED=true
export WATERMARK_BIT_STREAM="11001101"
```

### 代码中配置

最灵活的方式 - 直接在代码中配置：

```python
from oasis.watermark import WatermarkManager

# 创建水印管理器
watermark_mgr = WatermarkManager(
    enabled=True,
    bit_stream="11001101",
    delta=2.0,
    gamma=0.25,
    ecc_type="parity",
    log_dir="outputs/logs/watermark"
)

# 传递给 Agent
agent = SocialAgent(
    agent_id=0,
    watermark_manager=watermark_mgr
)
```

## 多Agent实验

### 场景 1: 少量 Agent 验证

**目标**: 快速验证水印功能

```python
from oasis.social_platform import Platform, PlatformConfig
from oasis.social_agent import SocialAgent
from oasis.watermark import WatermarkManager

# 配置
num_agents = 3
num_rounds = 5

# 创建平台
platform = Platform(PlatformConfig())

# 为每个 Agent 创建独立水印
agents = []
for i in range(num_agents):
    watermark_mgr = WatermarkManager(
        enabled=True,
        bit_stream=format(i, '08b'),  # 嵌入 Agent ID
        log_dir=f"outputs/logs/watermark"
    )
    
    agent = SocialAgent(
        agent_id=i,
        watermark_manager=watermark_mgr
    )
    agents.append(agent)

# 运行模拟
for round_num in range(num_rounds):
    for agent in agents:
        agent.perform_action()
    
    print(f"✅ Round {round_num + 1}/{num_rounds} completed")

print("✅ Simulation completed!")
```

```
            ├── watermark-agent0-20251111-143052.log
            ├── watermark-agent1-20251111-143052.log
            └── watermark-agent2-20251111-143052.log
```

### 场景 2: 大规模实验

**目标**: 测试系统扩展性

```python
import concurrent.futures
from tqdm import tqdm

# 配置
num_agents = 100
num_rounds = 10
max_workers = 10  # 并发数

# 创建 Agent 池
agents = []
for i in range(num_agents):
    watermark_mgr = WatermarkManager(
        enabled=True,
        bit_stream=format(i, '08b'),
        log_dir="outputs/logs/watermark"
    )
    
    agent = SocialAgent(
        agent_id=i,
        watermark_manager=watermark_mgr
    )
    agents.append(agent)

# 并发执行
def run_agent_round(agent):
    """单个 Agent 执行一轮"""
    return agent.perform_action()

# 运行模拟
for round_num in range(num_rounds):
    print(f"\n🔄 Round {round_num + 1}/{num_rounds}")
    
    with concurrent.futures.ThreadPoolExecutor(max_workers=max_workers) as executor:
        futures = [executor.submit(run_agent_round, agent) for agent in agents]
        
        # 显示进度条
        for _ in tqdm(concurrent.futures.as_completed(futures), total=len(agents)):
            pass
    
    print(f"✅ Round {round_num + 1} completed")

print("\n✅ All simulations completed!")
```

**性能提示**:

- ✅ 使用线程池并发执行
- ✅ 调整 `max_workers` 控制并发数
- ✅ 监控 API 速率限制

## 日志分析

### 日志文件结构

每个 Agent 生成一个独立的日志文件：

```
watermark-agent0-20251111-143052.log
```

**命名规则**: `watermark-agent{id}-{timestamp}.log`

### 日志格式

**JSONL 格式**（每行一个 JSON 对象）:

```json
{"round": 0, "behavior": "create_post", "prob_before": 0.35, "prob_after": 0.38, "bit": "1", "embedded": true}
{"round": 1, "behavior": "like_post", "prob_before": 0.28, "prob_after": 0.31, "bit": "1", "embedded": true}
{"round": 2, "behavior": "comment", "prob_before": 0.45, "prob_after": 0.45, "bit": "0", "embedded": false}
```

**字段说明**:

- `round`: 轮次编号（从 0 开始）
- `behavior`: 选择的行为
- `prob_before`: 嵌入前的概率
- `prob_after`: 嵌入后的概率
- `bit`: 嵌入的 bit 值（"0" 或 "1"）
- `embedded`: 是否成功嵌入

### 手动分析日志

#### 提取嵌入的 bits

```python
import json

# 读取日志
log_file = "outputs/logs/watermark/2025-11/watermark-agent0-20251111-143052.log"

embedded_bits = []
with open(log_file, 'r') as f:
    for line in f:
        entry = json.loads(line)
        if entry.get("embedded", False):
            embedded_bits.append(entry["bit"])

# 拼接为 bit stream
bit_stream = "".join(embedded_bits)
print(f"Embedded bits: {bit_stream}")
```

#### 计算嵌入统计

```python
import json

log_file = "outputs/logs/watermark/2025-11/watermark-agent0-20251111-143052.log"

total_rounds = 0
embedded_count = 0
skipped_count = 0

with open(log_file, 'r') as f:
    for line in f:
        entry = json.loads(line)
        total_rounds += 1
        
        if entry.get("embedded", False):
            embedded_count += 1
        else:
            skipped_count += 1

print(f"总轮数: {total_rounds}")
print(f"嵌入成功: {embedded_count} ({embedded_count/total_rounds*100:.1f}%)")
print(f"跳过嵌入: {skipped_count} ({skipped_count/total_rounds*100:.1f}%)")
```

## 高级配置

### 自定义 ECC 方法

虽然默认使用 Parity，但系统支持扩展：

```python
class CustomECC:
    """自定义 ECC 方法"""
    
    @staticmethod
    def encode(payload: str) -> str:
        """编码 payload"""
        # 实现你的编码逻辑
        encoded = payload + "0"  # 示例
        return encoded
    
    @staticmethod
    def decode(encoded: str) -> tuple:
        """解码并验证"""
        # 实现你的解码逻辑
        payload = encoded[:-1]
        valid = True
        return payload, valid

# 使用自定义 ECC
from oasis.watermark.coding_utils import ECCFactory

ECCFactory.register("custom", CustomECC)

watermark_mgr = WatermarkManager(
    enabled=True,
    bit_stream="11001101",
    ecc_type="custom"  # 使用自定义 ECC
)
```

### 自定义采样策略

修改差分采样的参数：

```python
# 参数说明
watermark_mgr = WatermarkManager(
    enabled=True,
    bit_stream="11001101",
    delta=2.0,   # 偏移强度（越大嵌入越强）
    gamma=0.25,  # 平滑系数（越大分布越平滑）
)
```

**参数调优建议**:

| 场景 | delta | gamma | 说明 |
|------|-------|-------|------|
| 高隐蔽性 | 1.0-1.5 | 0.15-0.20 | 嵌入轻微，难以检测 |
| 平衡（推荐） | 1.8-2.2 | 0.23-0.27 | 嵌入和隐蔽兼顾 |
| 高准确率 | 2.5-3.0 | 0.30-0.35 | 嵌入强烈，易于验证 |

### 5. API 速率限制

**建议**: 添加速率限制保护

```python
import time
from functools import wraps

def rate_limit(calls_per_second=10):
    """限制函数调用频率"""
    min_interval = 1.0 / calls_per_second
    last_called = [0.0]
    
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            elapsed = time.time() - last_called[0]
            left_to_wait = min_interval - elapsed
            
            if left_to_wait > 0:
                time.sleep(left_to_wait)
            
            ret = func(*args, **kwargs)
            last_called[0] = time.time()
            return ret
        
        return wrapper
    return decorator

# 应用到 LLM 调用
@rate_limit(calls_per_second=5)  # 限制每秒 5 次
def call_llm(prompt):
    return model.generate(prompt)
```
