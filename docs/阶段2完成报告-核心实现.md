#### ✅ 方法 1: `_build_action_context()`

**位置**: `oasis/social_agent/agent.py` (lines ~143-156)

**功能**: 构建上下文密钥字符串（用于 PRG 种子）

**实现**:
```python
def _build_action_context(self) -> str:
    """使用最近 3 个行为作为上下文"""
    if not hasattr(self, '_action_history'):
        self._action_history = []
    
    window_size = 3
    recent_actions = self._action_history[-window_size:]
    return "||".join(recent_actions) if recent_actions else ""
```

**特点**:
- 滑动窗口大小：3
- 格式：`"like_post||create_comment||follow"`
- 与 `demo_watermark_with_deepseek.py` 保持一致

# 🎯 水印集成点：两阶段调用法
if self.watermark_manager and self.watermark_manager.enabled:
    # === 阶段 1: 获取概率 ===
    probabilities = await self._get_action_probabilities(env_prompt)
    
    # === 阶段 2: 水印采样 ===
    selected_action, target_list, bits_embedded, context = \
        self.watermark_manager.sample_behavior_watermark(
            probabilities=probabilities,
            round_num=round_num,
            context_for_key=self._build_action_context()
        )
    
    # === 阶段 3: 执行行为 ===
    response = await self._execute_watermarked_action(
        selected_action, env_prompt
    )
    
    # 更新统计
    self.watermark_manager.stats['rounds_completed'] += 1
    
    return response
else:
    # 无水印：正常流程
    ...

## 📈 技术细节

### 集成方式：两阶段调用法

**优点**:
- ✅ 不修改 CAMEL 源码
- ✅ 完全控制概率修改
- ✅ 向后兼容
- ✅ 可验证性强

**缺点**:
- ⚠️ 需要 2 次 LLM 调用
- ⚠️ 延迟增加约 100%
- ⚠️ 成本增加约 100%

### 性能影响

| 操作 | 无水印 | 带水印 | 增加 |
|------|--------|--------|------|
| LLM 调用 | 1次 | 2次 | +100% |
| 延迟 | ~3秒 | ~6秒 | +3秒 |
| Tokens | ~800 | ~1300 | +500 |

**100 轮模拟成本估算**:
- 总 tokens: ~130,000
- GPT-4O-MINI: ~$0.02
- ✅ 研究项目可接受

### 错误处理

**多层防护**:
1. **概率获取失败** → 均匀分布
2. **JSON 解析失败** → 正则提取 + 回退
3. **水印集成失败** → 降级到正常模式
4. **行为执行失败** → 记录警告 + 继续

**鲁棒性**: ✅ 高

## 📝 使用示例

### 基础用法

```python
from oasis import SocialAgent, UserInfo
from oasis.watermark import WatermarkManager

# 1. 创建水印管理器
wm = WatermarkManager(
    enabled=True,
    mode="full",
    bit_stream="11001101",
    config={
        "payload_bit_length": 8,
        "ecc_method": "parity",
        "embedding_strategy": "cyclic"
    }
)

# 2. 创建带水印的 Agent
agent = SocialAgent(
    agent_id=0,
    user_info=UserInfo(...),
    watermark_manager=wm,  # 🎯 关键集成点
    ...
)

# 3. 正常使用（水印自动嵌入）
actions = {agent: LLMAction()}
await env.step(actions)

# 4. 提取验证
extracted, stats = wm.extract_watermark_from_log()
```
