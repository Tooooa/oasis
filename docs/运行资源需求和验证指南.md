## 🔑 1. AI API 需求

### 为什么需要 API？

示例使用 **GPT-4O-MINI** 模拟 3 个智能体在社交平台上的行为：

```python
openai_model = ModelFactory.create(
    model_platform=ModelPlatformType.OPENAI,
    model_type=ModelType.GPT_4O_MINI,  # 使用 GPT-4O-MINI
)
```

### API 调用详情

| 参数 | 值 |
|------|-----|
| **模型** | GPT-4O-MINI |
| **智能体数量** | 3 个 |
| **模拟轮数** | 5 轮 |
| **总调用次数** | 15 次 (3 × 5) |
| **每次调用目的** | 决定智能体行为 (like/post/comment/follow/refresh) |

### 成本估算

GPT-4O-MINI 定价（2024年11月）：
- Input: $0.00015 per 1K tokens
- Output: $0.0006 per 1K tokens

**预计成本**: < **$0.05** (不到 5 美分)

### 设置 API Key

**Windows PowerShell:**
```powershell
$env:OPENAI_API_KEY = "sk-your-api-key-here"
```

**Linux/Mac:**
```bash
export OPENAI_API_KEY="sk-your-api-key-here"
```

**永久设置 (推荐):**
创建 `.env` 文件或添加到系统环境变量

## 💻 2. 算力需求

### 硬件需求

| 资源 | 最低要求 | 推荐配置 | 说明 |
|------|---------|---------|------|
| **CPU** | 2核 2.0 GHz | 4核 2.5 GHz+ | 水印算法是 CPU 密集型 |
| **内存** | 2 GB | 4 GB | Python + PyTorch + OASIS |
| **GPU** | ❌ 不需要 | ❌ 不需要 | 无深度学习训练 |
| **磁盘** | 100 MB | 500 MB | 日志 + 数据库 |
| **网络** | 稳定网络 | 高速网络 | 调用 OpenAI API |

### 为什么不需要 GPU？

AgentMark 水印技术使用的算法：
- ✅ 差分水印重组 → CPU 排序和索引操作
- ✅ 循环均匀编码 → CPU 位运算
- ✅ 纠错码 (Parity/Hamming) → CPU 逻辑运算
- ✅ HMAC-SHA256 密钥生成 → CPU 哈希运算

**没有涉及：**
- ❌ 神经网络训练
- ❌ 大规模矩阵运算
- ❌ 模型推理（模型在 OpenAI 云端）

### 运行时间估算

```
初始化         : ~2 秒
每轮模拟       : 20-40 秒 (3个智能体 × LLM调用)
5轮总时间      : 2-4 分钟
水印提取验证   : ~1 秒
总计          : 2-5 分钟
```

时间主要取决于：
1. OpenAI API 响应速度（主要因素）
2. 网络延迟
3. CPU 性能（次要因素）

## 🔬 4. 验证原理详解

### 完整工作流程

```
┌─────────────────┐
│ 原始载荷        │  "11001101" (8 bits)
│ Original        │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 添加纠错码      │  add_parity_bit()
│ ECC Encoding    │  → "110011010" (9 bits)
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 差分水印嵌入    │  differential_based_recombination()
│ Differential    │  → 修改概率分布的目标列表
│ Watermarking    │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 智能体行为      │  Agent 根据修改后的概率选择行为
│ Agent Actions   │  (like_post, create_post, comment, etc.)
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 日志记录        │  JSON 格式记录到 log/watermark-*.log
│ Logging         │  包含: round, probabilities, target_list
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 提取目标列表    │  从日志 JSON 解析 target_list
│ Extract Targets │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 差分解码        │  differential_based_decoder()
│ Differential    │  → "110011010" (9 bits)
│ Decoding        │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 纠错码验证      │  check_and_strip_parity_bit()
│ ECC Validation  │  → "11001101" (8 bits) + Valid: True
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 比对验证        │  decoded == original?
│ Verification    │  → ✅ SUCCESS!
└─────────────────┘
```

### 关键验证点

| 验证点 | 方法 | 通过标准 |
|-------|------|---------|
| **1. 比特流长度** | `len(bit_stream)` | = 载荷长度 + ECC开销 |
| **2. 嵌入完整性** | `bits_embedded` 统计 | = bit_stream 长度 |
| **3. 日志格式** | JSON 解析 | 成功解析所有轮次 |
| **4. 提取完整性** | `extracted_bit_stream` | 长度 = bit_stream |
| **5. 奇偶校验** | `check_parity` | Valid: True |
| **6. 载荷匹配** | 字符串比对 | decoded == original |

## ❓ 7. 常见问题

### Q1: 没有 OpenAI API 怎么办？

**选项 1:** 使用轻量级测试
```bash
python examples/test_watermark_only.py
```

**选项 2:** 使用本地模型（需要修改代码）
```python
# 替换为 Ollama 或其他本地模型
from camel.models import ModelFactory
model = ModelFactory.create(
    model_platform=ModelPlatformType.OLLAMA,
    model_type="llama3",
)
```

**选项 3:** 使用其他云端 API
- Azure OpenAI
- Anthropic Claude
- Google Gemini

### Q2: 运行时间太长怎么办？

**优化建议:**

```python
# 减少轮数
num_rounds = 2  # 原来是 5

# 减少智能体数量
for i in range(1):  # 原来是 3
    ...
```

### Q3: 如何验证 GPU 没有被使用？

**检查方法:**

```powershell
# Windows: 任务管理器 → 性能 → GPU
# 运行示例时 GPU 使用率应该是 0%

# 或使用 PyTorch 检查
python -c "import torch; print('CUDA available:', torch.cuda.is_available())"
# 输出: CUDA available: False (或 True 但不会被使用)
```

### Q4: 成本会超过预期吗？

**不会！** 因为：
- 使用 GPT-4O-MINI（最便宜的模型）
- 只有 15 次简单调用
- 每次输入很短（行为选项）
- 每次输出很短（一个行为名称）

**最坏情况:** < $0.10

### Q5: 如何确认水印真的有效？

**验证方法:**

1. **查看日志文件**
```powershell
cat log/watermark-*.log | Select-String "target_list"
# 应该看到每轮的目标列表
```

2. **手动验证**
```python
# 从日志手动提取并验证
import json
with open("log/watermark-xxx.log") as f:
    for line in f:
        data = json.loads(line)
        print(f"Round {data['round']}: {data['target_list']}")
```

3. **检查统计匹配**
```
bits_embedded = 9  # 应该等于
bit_stream_length = 9  # 这两个数字
```
