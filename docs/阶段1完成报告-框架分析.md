## 📊 关键发现

### 1. CAMEL 框架结构

```python
ChatAgentResponse {

    info: Dict[str, Any]           # 包含 tool_calls 等信息

```

**工具调用信息位置**: `response.info['tool_calls']`

### 2. OpenAI API 支持

✅ **支持 logprobs 参数**:
- 可以返回 token 的对数概率
- 可以获取 top_logprobs (前 N 个候选)
- 通过 `model_config_dict` 传递参数

### 3. 集成挑战

❌ **直接获取工具概率困难**:
- CAMEL 不直接暴露工具选择的概率分布
- `astep()` 返回的是已执行的工具调用
- logprobs 主要用于文本生成，不是工具选择

---

## 💡 推荐方案：两阶段调用法

### 核心思路

**不直接修改 LLM 的工具选择概率，而是：**

1. **第一次调用 LLM**: 让它返回所有可用行为的概率分布（JSON 格式）
2. **水印处理**: 使用 WatermarkManager 修改概率
3. **第二次调用**: 使用 `perform_action_by_data()` 强制执行选定的行为

### 优点

✅ **不需要修改 CAMEL 源码**  
✅ **完全控制概率修改过程**  
✅ **向后兼容** - 无水印时走正常流程  
✅ **可验证** - 概率分布明确可见  
✅ **灵活** - 可以调整提示词获得更好的概率

### 缺点

⚠️ **额外的 LLM 调用** - 增加延迟和成本  
⚠️ **概率可能不够准确** - 依赖 LLM 的概率估计

### 修改 `SocialAgent.perform_action_by_llm()`

```python
async def perform_action_by_llm(self):
    """
    执行 LLM 驱动的行为决策
    
    如果启用水印:
        1. 先获取概率分布
        2. 水印修改概率
        3. 执行选定行为
    否则:
        正常 LLM 流程
    """
    # 获取环境观察
    env_prompt = await self.env.to_text_prompt()
    
    # 🎯 水印集成点
    if self.watermark_manager and self.watermark_manager.enabled:
        # === 阶段 1: 获取概率 ===
        probabilities = await self._get_action_probabilities(env_prompt)
        
        # === 阶段 2: 水印采样 ===
        selected_action, target_list, bits_embedded, context = \
            self.watermark_manager.sample_behavior_watermark(
                probabilities=probabilities,
                round_num=self.watermark_manager.stats.get('rounds_completed', 0),
                context_for_key=self._build_action_context()
            )
        
        # === 阶段 3: 执行行为 ===
        # 使用 LLM 生成参数，但强制使用选定的行为
        response = await self._execute_watermarked_action(
            selected_action, env_prompt
        )
        
        # 更新统计
        self.watermark_manager.stats['rounds_completed'] += 1
        
        return response
    else:
        # 无水印：正常流程
        user_msg = BaseMessage.make_user_message(
            role_name="User",
            content=f"Please perform social media actions after observing the "
                    f"platform environments. Here is your social media environment: "
                    f"{env_prompt}"
        )
        return await self.astep(user_msg)
```

### 辅助方法 1: `_get_action_probabilities()`

```python
async def _get_action_probabilities(self, env_prompt: str) -> dict[str, float]:
    """
    通过 LLM 获取所有可用行为的概率分布
    
    策略: 让 LLM 返回 JSON 格式的概率估计
    
    Args:
        env_prompt: 环境观察描述
        
    Returns:
        dict: {"like_post": 0.3, "create_comment": 0.25, ...}
    """
    # 获取所有可用行为名称
    available_actions = [tool.func.__name__ for tool in self.action_tools]
    actions_str = ", ".join(available_actions)
    
    # 构造概率查询提示
    prompt = f"""You are observing a social media environment:
{env_prompt}

Based on this observation and your profile, estimate the probability of performing each action.
Return ONLY a JSON object with probabilities (must sum to 1.0):

Available actions: {actions_str}

Output format:
{{"action_name": probability, ...}}

Example:
{{"like_post": 0.3, "create_comment": 0.25, "follow": 0.2, ...}}
"""
    
    # 调用 LLM
    user_msg = BaseMessage.make_user_message(
        role_name="User",
        content=prompt
    )
    
    response = await self.astep(user_msg)
    
    # 解析 JSON 响应
    import json
    import re
    
    content = response.msgs[0].content
    
    # 提取 JSON
    json_match = re.search(r'\{[^}]+\}', content)
    if json_match:
        probabilities = json.loads(json_match.group())
        
        # 归一化
        total = sum(probabilities.values())
        if total > 0:
            probabilities = {k: v/total for k, v in probabilities.items()}
        
        return probabilities
    else:
        # 回退：均匀分布
        agent_log.warning(f"Agent {self.social_agent_id}: Failed to parse probabilities, using uniform")
        return {action: 1.0/len(available_actions) for action in available_actions}
```

### 辅助方法 2: `_build_action_context()`

```python
def _build_action_context(self) -> str:
    """
    构建上下文密钥字符串（用于 PRG 种子）
    
    使用最近 3 个行为作为上下文
    
    Returns:
        str: "like_post||create_comment||follow"
    """
    if not hasattr(self, '_action_history'):
        self._action_history = []
    
    window_size = 3
    recent_actions = self._action_history[-window_size:]
    return "||".join(recent_actions) if recent_actions else ""
```

### 辅助方法 3: `_execute_watermarked_action()`

```python
async def _execute_watermarked_action(
    self, 
    action_name: str, 
    env_prompt: str
) -> Any:
    """
    执行水印选定的行为
    
    策略: 让 LLM 为选定的行为生成参数
    
    Args:
        action_name: 要执行的行为名称（由水印选择）
        env_prompt: 环境观察
        
    Returns:
        执行结果
    """
    # 构造强制执行的提示
    prompt = f"""You are observing a social media environment:
{env_prompt}

You MUST perform the action: {action_name}

Generate appropriate arguments for this action and execute it.
"""
    
    user_msg = BaseMessage.make_user_message(
        role_name="User",
        content=prompt
    )
    
    # 调用 LLM，它会自动选择工具并执行
    response = await self.astep(user_msg)
    
    # 记录到历史
    if not hasattr(self, '_action_history'):
        self._action_history = []
    self._action_history.append(action_name)
    
    # 处理工具调用
    if 'tool_calls' in response.info:
        for tool_call in response.info['tool_calls']:
            executed_action = tool_call.tool_name
            args = tool_call.args
            
            agent_log.info(
                f"Agent {self.social_agent_id} - Watermark selected: {action_name}, "
                f"LLM executed: {executed_action}"
            )
            
            # 验证 LLM 是否执行了正确的行为
            if executed_action != action_name:
                agent_log.warning(
                    f"Agent {self.social_agent_id} - LLM executed {executed_action} "
                    f"instead of watermark-selected {action_name}"
                )
    
    return response
```
